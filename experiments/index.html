Launcher Experiments

This prototype tests a Roblox-style handoff where the website triggers a local Site-89 launcher if installed, with a direct modpack download fallback.

Site-89 Modpack Launcher (Prototype)

Use Install / Update Modpack to download the current zip package. Use Play to attempt launching a future local Site-89 launcher via custom protocol.

Ready. Install/update downloads the ZIP now. Play attempts a local launcher handoff.
Modpack URL:

Web browsers cannot create arbitrary folders or start `.exe` files directly. Full one-click setup requires a desktop launcher application registered to a protocol like site89://.

Current Flow

  1. Click Install / Update Modpack.
  2. ZIP downloads from your current source.
  3. Click Play to try protocol launch.
  4. If launcher is missing, download prompt/status explains next step.
